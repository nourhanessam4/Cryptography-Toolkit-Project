# Crypto Toolkit

A simple cryptography toolkit built with Python and Streamlit. The project provides a web interface for performing different cryptographic operations including encryption, decryption, encoding, decoding, and hashing.

## Project Features

### Symmetric Encryption

The project supports three symmetric encryption algorithms:

* AES
* DES
* 3DES

The user can enter a plaintext message and choose an algorithm to encrypt it. The encrypted result is returned in Base64 format.

The same key can then be used to decrypt the encrypted message and recover the original plaintext.

For the implemented algorithms:

* AES uses CBC mode with a 256-bit key.
* DES uses CBC mode with an 8-byte key.
* 3DES uses CBC mode with a 24-byte key.
* A random IV is generated for each encryption operation.
* PKCS#7 padding is used before encryption.

The project also supports using either a default key or a user-provided secret key.

### RSA Asymmetric Encryption

The RSA section uses a 2048-bit RSA key pair.

It provides:

* RSA key generation
* Public key encryption
* Private key decryption
* OAEP padding
* Base64 encoding of the encrypted result

A new RSA key pair can be generated from the application when needed.

### Encoding and Decoding

The project supports three encoding methods:

* Base64
* Hexadecimal
* URL Encoding

Both encoding and decoding operations are available.

These methods are used for data representation and are different from encryption because they do not provide confidentiality.

### Hashing

The hashing section supports:

* SHA-256
* SHA-512

The user can choose between:

* Random Salt
* Custom Salt
* No Salt

For random salt, a 16-byte value is generated and combined with the input before calculating the hash.

The application displays the selected algorithm, salt, and resulting hash.

## How It Works

### Symmetric Encryption

The entered key is processed using SHA-256 and converted to the required key length for the selected algorithm.

For encryption:

```text
Plaintext
   ↓
Key Processing
   ↓
AES / DES / 3DES
   ↓
CBC Encryption
   ↓
IV + Ciphertext
   ↓
Base64
   ↓
Encrypted Text
```

For decryption, the IV is extracted from the encrypted data and used together with the ciphertext to recover the original plaintext.

### RSA Encryption

A 2048-bit RSA key pair is generated by the application.

```text
Plaintext
   ↓
Public Key
   ↓
RSA-OAEP
   ↓
Encrypted Data
   ↓
Base64
```

The encrypted data is decrypted using the corresponding private key.

### Hashing

```text
Input
   ↓
Optional Salt
   ↓
SHA-256 / SHA-512
   ↓
Hash
```

## Security Notes

This project is mainly for learning and demonstrating cryptographic concepts.

DES and 3DES are included for educational purposes and are not recommended for modern secure applications.

AES is the stronger symmetric encryption option available in this project. The current implementation uses CBC mode, which provides encryption but does not provide authentication by itself.

The default key included in the application is only intended for testing and demonstration.
